# Backend Development Guidelines

Правила действуют для `backend/`, Prisma, auth, API routes, серверных утилит и
серверного кода в `packages/*`.

## Boundaries

- Не включай серверные зависимости в клиентские точки входа пакетов.
- Используй публичные API между модулями.
- Проверяй входящие HTTP- и Socket.IO-данные.
- Проверяй авторизацию перед защищёнными действиями.
- Подтверждай запрос только после успешного сохранения данных.
- Не раскрывай секреты и содержимое env-файлов.

## Workflow

Используй актуальные scripts из корневого `package.json`. Для PostgreSQL
применяй `db:start`, `db:stop`, `db:migrate` и `db:seed`.

Для сложных или неоднозначных изменений сначала предложи краткий план. После
изменения запускай минимальный релевантный набор проверок; полный набор — по
явному запросу или при широком влиянии.
