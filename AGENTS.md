# Repository Guidelines

- Отвечай на русском языке.
- Используй Node.js 24+ и `pnpm`; запускай команды из корня репозитория.
- Перед изменением изучи связанные файлы и применимый локальный `AGENTS.md`.
- Не изменяй несвязанные файлы и не добавляй зависимости без необходимости.
- Не утверждай, что проверка прошла, если она не запускалась.

## Scope

- Frontend и UI-пакеты: `frontend/AGENTS.md`.
- Backend, Prisma, auth и API: `backend/AGENTS.md`.
- Пакеты импортируй через публичные точки входа `@dashboard/*`.
- Пакетам запрещено импортировать код из `frontend/` и корневого `lib/`.

## Verification

Используй актуальные scripts из `package.json`. Запускай минимальный
релевантный набор проверок; полный набор — по явному запросу или при широком
влиянии изменений.
