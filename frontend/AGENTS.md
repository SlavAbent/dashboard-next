# Frontend Development Guidelines

Правила действуют для `frontend/` и UI-кода в `packages/*/src/`. Для auth,
API и серверного доступа к данным используй `backend/AGENTS.md`.

## Architecture

- Соблюдай FSD из `frontend/FSD.md` и импортируй только из нижележащих слоёв.
- Используй публичные API слайсов и пакетов `@dashboard/*`.
- Общие компоненты и иконки размещай в `shared/components` и `shared/icons`.
- Пакеты не должны импортировать `frontend/` или корневой `lib/`.

## Workflow

Для сложных или неоднозначных изменений сначала предложи краткий план. Для
локальных исправлений действуй сразу, если границы задачи ясны.

После изменения запускай только релевантные проверки из `package.json`.
Полный набор тестов запускай по явному запросу или при широком влиянии.

## Style

Соблюдай существующие TypeScript, React, naming, ESLint, Prettier и Tailwind
соглашения. Публичные API предоставляй через `index.ts`, где это принято.
